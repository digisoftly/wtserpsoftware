# **App Name**: WarriorERP

## Core Features:

- Multi-Tenant Company & Branch Management: Establish and manage a multi-company and multi-branch hierarchy with integrated Row-Level Security (RLS) policies for data isolation.
- Dynamic Role-Based Access Control: Define and manage granular user roles and permissions (Admin, Manager, Staff, Employee, Customer, Technician) to control module and data access across companies and branches.
- Customizable KPI Dashboard & Reporting: Display real-time Key Performance Indicators (KPIs) with auto-refresh functionality on a clean, customizable dashboard layout for different user roles. Generate essential PDF reports like Invoices and Payslips.
- Core Sales & Purchase Workflows: Manage sales invoicing and purchase order processing, including serial number tracking, automatic stock deduction/addition, and customer/supplier ledger updates.
- Product, Inventory & Service Management: Maintain a comprehensive catalog of products and services, manage inventory levels, track serial numbers, and trigger low stock alerts.
- Generative AI Forecasting Tool: Leverage a generative AI tool to analyze historical sales data and current inventory to provide demand forecasts, alongside explanations and potential recommendations for stock optimization.
- Supabase Integration & Offline-First Data Sync: Connect to Supabase PostgreSQL for cloud data storage and implement offline-first synchronization logic, allowing mobile users to operate disconnected and resolve data conflicts.

## Style Guidelines:

- Primary color: A sophisticated blue (#226FDB) to evoke reliability and professionalism, contrasting against lighter elements.
- Background color: A very light, almost white, blue-grey (#ECF0F4) for a clean, minimal base.
- Accent color: A vibrant cyan (#2ED6F7) to highlight key actions, alerts, and provide visual interest.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, technical aesthetic; Body text font: 'Inter' (sans-serif) for clear readability in data-rich tables and forms.
- Employ crisp, outline-style icons with varying, module-specific colors for easy identification within the sidebar and KPI cards, maintaining a flat aesthetic.
- Implement a fully responsive design with a collapsible, draggable, mobile-friendly sidebar featuring colorful module icons, rounded cards for content blocks, minimal shadows, and floating quick-add buttons for accessibility.
- Subtle animations for KPI auto-refresh and seamless transitions in navigation, enhancing the user experience without being distracting.
